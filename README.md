# PySpark & SQL Practice Notebook

## Overview
Personal practice notebook covering PySpark, SQL, and Python fundamentals
for data engineering interview preparation. Built using Databricks Community
Edition.

## Topics Covered
- PySpark DataFrame API — schema definition, transformations, actions
- Window functions — ROW_NUMBER, RANK, LAG, LEAD
- Joins, groupBy, aggregations

## Topics to be Added
- Python data structures — collections, generators, comprehensions
- SQL patterns — deduplication, CTEs, NULL handling
- Delta Lake basics — MERGE, SCD Type 1 & 2

## Stack
- Python 3.x
- PySpark (Databricks runtime)
- Databricks Community Edition

## How to Use
Open in Databricks by importing the `.ipynb` file via
**Workspace → Import → File**. Each section is self-contained
and can be run independently.
